# Лабораторные работы Java: 3–9

Каждая папка — самостоятельная лабораторная с исходным кодом и подробным README для подготовки к защите:

- `lab3` — интерфейсы, полиморфизм, стратегии и sealed-типы.
- `lab4` — исключения, обработка ошибок и JUnit.
- `lab5` — коллекции, generics, LRU и граф зависимостей.
- `lab6` — строки, числа, деньги, даты и время.
- `lab7` — файлы, потоки, импорт и бинарные форматы.
- `lab8` — лямбды, Stream API и однопроходная статистика.
- `lab9` — потоки, синхронизация и конкурентные коллекции.

Для работ 3–6 и 8–9 используется Java 21+ и Maven, для работы 7 достаточно JDK 11+. Начните с README нужной папки: там описаны запуск, смысл классов и разбор заданий. JUnit-тесты 3–6 и 8–9 запускаются командой `mvn test` внутри соответствующей папки, проверка 7 — командами из её README.

На этом компьютере JDK и Maven настроены в пользовательских переменных среды. Откройте новое окно PowerShell и проверьте:

```powershell
java -version
javac -version
mvn -version
```

JDK расположен в `C:\Program Files\Java\jdk-27.0.1.0.3`, Maven — в `%LOCALAPPDATA%\Programs\Apache\apache-maven-3.9.11`. Уже открытым терминалам может потребоваться перезапуск, чтобы увидеть новые переменные.
